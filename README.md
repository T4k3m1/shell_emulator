# Shell Emulator

Учебный проект эмулятора командной строки (REPL) на Python.

## Структура проекта
- src/ — исходный код проекта.
- tests/ — тестовые наборы и скрипты.
- run.bat — скрипт запуска эмулятора.

## Требования
- Python 3.8+

## Запуск
Выполните скрипт `run.bat` или запустите напрямую через коммандную строку:

py src/emulator.py
